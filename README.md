# curriculo

Meu currículo profissional online, desenvolvido com HTML e CSS.

## Overview
Este repositório contém o código-fonte do meu currículo profissional, estruturado de forma clara e acessível na web. O projeto foca em uma apresentação limpa e responsiva das minhas experiências e habilidades.

## Tecnologias
- HTML5
- CSS3

## Uso
Para visualizar o currículo localmente:
1. Clone o repositório.
2. Abra o arquivo `index.html` em seu navegador de preferência.
